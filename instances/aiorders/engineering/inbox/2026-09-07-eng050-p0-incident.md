# P0 — two production database functions can be called by anyone, no login required

**What's wrong.** Two functions in the `aiorders-api` database
(`calculate_platform_analytics`, behind the platform-wide analytics
numbers, and `get_acquisition_breakdown`, behind the brand portal's
marketing-channel report) only grant access to the app's own backend
service — but this project's database also has a separate, default setting
that quietly hands the same access to `anon` and `authenticated` too.
`anon` means no login at all.

**What that means concretely.** Anyone who has this project's public app
key — which is meant to be public, it ships inside every one of our own
frontend web pages — can call either function directly and get back the
platform-wide order/revenue numbers, or any single restaurant's
acquisition-channel breakdown, without logging in and without going through
the app at all.

**Why this is reaching you now instead of Friday's report.** Same rule
`ENG-022`, `ENG-029`, `ENG-030`, `ENG-035`, and `ENG-036` used — a
confirmed, repeatable ability to call a production function with no
authentication is a live exploit in its own right
(`agents/eng-manager/config/security-baseline.md`), independent of how
sensitive the returned numbers are. In this case the numbers themselves are
business metrics (revenue, order/customer counts) — no customer PII, no
credentials, no payment data.

**What's already happening.** This doesn't need your approval to start —
`security`-typed tickets skip the approval step by design. `ENG-050` is
filed and handed to the architect for the design step; the fix itself
(explicitly naming both roles in the `revoke`) was already proven earlier
today fixing the identical gap on `ENG-048`. Full evidence on the ticket:
`agents/eng-manager/board/ENG-050-rpc-execute-grant-exposure.md`.

**How this was found.** Not a security sweep — principal-engineer noticed
the pattern while reviewing `ENG-048`'s own database work, then checked the
rest of the project. Security confirmed these two are actually live and
reachable today, the same afternoon.

**What would help from you, if anything.** Nothing is required. If you want
this to jump ahead of everything else in flight, you can set `priority:
now` on `ENG-050` — that's the one thing only you can do here. Otherwise it
proceeds at its own severity's normal speed.
