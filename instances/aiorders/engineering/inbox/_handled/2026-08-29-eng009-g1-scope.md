# G1 — Influencer engagement info — internal activity signal plus a staff-editable social stat

## Readback

**You said:** "i mean both reading a and reading B. reading A is something
we can start with now so we know how active the particular influencer is.
reading B is something our staff can update or later we can connect using
some api from meta." (answering
`inbox/_handled/2026-08-29-eng008-engagement-source-question.md`)

**Understood as:** Both signals, built now: an internal activity indicator
derived from existing data, and a social-media figure staff enter and
update by hand. A live Meta API connection is explicitly future work per
your own words, not part of this ticket.

**Requirements:**
1. `[confirmed]` Staff see an internally-derived activity indicator.
2. `[confirmed]` Staff can enter/update a social-media figure by hand.
3. `[inferred]` The two are shown distinctly, not merged into one number.
4. `[proposed]` The manual figure shows when it was last updated.

**Not doing (this ticket):** any live social-platform API integration —
deferred by your own words to later; a history of past social figures;
automated recalculation on a schedule.

## Recommendation

**Build ENG-009 now.** Small, no new vendor, no new auth — it's a direct
follow-on to the answer you just gave on `ENG-008`'s standing question, and
it's cheap because the Meta API half is deliberately not in this ticket.

## Problem

Staff have no way to see how active an influencer is on AIOrders or record
their social reach, even informally.

## Acceptance criteria

1. `[confirmed]` Given an influencer with campaign/collaboration history,
   when staff view their admin record, then a derived activity indicator
   is displayed.
2. `[confirmed]` Given no social figure set, when staff enter one, then it
   displays and persists.
3. `[confirmed]` Given a social figure already set, when staff update it,
   then the board reflects the new value.
4. `[proposed]` Given a social figure that's been set, then the board also
   shows when it was last updated.

## Non-goals

Live Meta/Instagram/TikTok API integration (explicitly deferred); OAuth or
any influencer-side account connection; a history of past social figures;
scheduled automatic recalculation.

## Risks and unknowns

The concrete internal measure behind "activity" is an architect decision,
not fixed here — doesn't change the acceptance criteria. No hard
dependency on `ENG-008`, but sequenced after it to avoid two tickets
editing the same admin-UI file concurrently.

## Cost

Build: `S`. Run: `$0/month` — the API connection that would cost money is
explicitly excluded from this ticket.
