## Round-1 and round-2 gaps this ticket's own gate found and closed

Code review round 1 (2026-09-02) failed on a stale-response race in the
frontend notes UI — not an authorization or persistence defect, so it
didn't reopen any AC above; QA's hop was not run that round (discarded per
the combined-hop design). Round 2 failed on missing row-level security on
`influencer_notes` — this one **does** bear directly on AC4, since the
gap was a second, unmediated path to the exact thing AC4 requires be
rejected. Both fixes are re-verified by principal-engineer's own round-3
review (`agents/principal-engineer/reviews/ENG-010.md`); this is QA's
first pass on this ticket, run against the fixed code, not the original
submission.
