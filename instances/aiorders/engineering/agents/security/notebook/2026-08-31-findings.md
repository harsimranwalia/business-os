## ENG-013 (aiorders-api) — raw `error.message` returned in a 500 response body

**Category:** A05 Security Misconfiguration (verbose error).
**Severity:** Low. Occurrence: 1 of 3 (three-strike tracking starts here).

`setStageOverride`/`resetStageOverride` in `admin-portal/handlers/foodswipe.ts`
both catch and return `error instanceof Error ? error.message : 'Unknown
error'` directly in the client-facing 500 body. Not blocking this ticket's
gate: the route is role-gated before either function runs (only
admin/sub-admin ever sees the message), and the pattern is copied verbatim
from this same file's pre-existing `GET` catch block, not introduced fresh
by this diff. Worth tracking because it is now present in at least this one
handler in two write actions; if it recurs in a third handler, it is a
standards-promotion candidate for `engineering-standards.md`
(principal-engineer owns that edit, per the three-strike rule — security
proposes, doesn't write).

**Next occurrence:** check this entry before re-filing as a fresh finding.
