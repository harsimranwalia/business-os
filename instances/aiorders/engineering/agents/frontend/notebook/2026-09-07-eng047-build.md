## PR body (for release-readiness to use verbatim)

**What it does:** Adds an "Open Now" quick-filter chip to `FilterBar`, shown
on all three tabs (Order Food / Dine In / Catering). Threads the resulting
`openNow` boolean from `FilterState` through `useRestaurants` to
`apiService.getRestaurants`, sent as the `open_now` query param (snake_case,
matching `ENG-045`'s `aiorders-api` handler). Renders a closed-restaurant
`status` label (e.g. "Closed · opens 11 AM") in the existing card meta row
when the backend reports one — no client-side hours logic added, the server
already computed it (ADR-010).

**What it deliberately does not do:** No hours parsing or evaluation here —
purely renders what `ENG-045`'s handler computes. Doesn't reset `openNow`
when the active tab changes (unlike the Offers/Rating 4+ quick filters it's
styled after) — "show me who's open right now" is a standing intent across
tabs, per the design. Doesn't touch `RestaurantDetail.tsx` (separate,
untouched client-side hours display) or either of `ENG-045`'s/`ENG-046`'s
own repos.

**Depends on `ENG-045`** (`aiorders-api` PR #20, open, not yet merged) for
the `open_now` filtering and `status` field this ticket's diff reads —
functional dependency only; no git-level stacking, since the two tickets are
in different repos. This PR is safe to merge before `ENG-045`'s (new fields
are additive and simply won't be populated by the API yet — no runtime
break, the chip will show but `open_now=true` filters nothing and no
restaurant will show a `status` label until `ENG-045` ships), but the
feature only does anything once both are live.

**Uncertainties / what to look at hardest:** `RestaurantCard`'s three unused
`has_*` fields — intentional per the design's own Components row, but worth
confirming that's still wanted rather than a leftover from before the
list/detail response split was decided. `npm run lint` is unrunnable on this
repo (pre-existing `.eslintrc.cjs` syntax error, unrelated to this diff,
proposal filed) — review leaned on `tsc --noEmit` and `vite build` passing
clean instead.
