## Test quality (shape, not coverage — QA owns coverage, this is whether the tests are worth anything)

- **The tenant-scoping test is mutation-sensitive, not just
  shape-sensitive.** `adminAuthRecordingEq` records every `.eq()` call the
  handler makes against a fake chain and asserts the exact sequence
  `[['id', profileId], ['source', 'foodswipe']]`. Deleting the
  `.eq('source', 'foodswipe')` call from either write action — the precise
  regression round 1 was raised to prevent — would shrink that array by one
  entry and fail the assertion for the reason it exists, not for an
  incidental reason. Traced by hand rather than executed, per the gap
  above, but the assertion shape itself is sound.
- **The `Boolean(...)` regression test is real, not decorative.**
  `hasFoodswipeAccess({ role: "restaurant" })` (no `additional_roles`)
  exercises exactly the branch where the pre-fix code returned `undefined`
  instead of `false` — `false || (undefined && ...)` evaluates to
  `undefined`. `assertEquals(..., false)` is a strict equality check, so
  reverting the `Boolean(...)` wrap would fail this specific test, even
  though the handler's own `if (!hasFoodswipeAccess(...))` branch would
  still behave identically either way (`!undefined === !false === true`).
  Confirmed by hand-evaluating both branches; not asserting on an
  implementation detail — `hasFoodswipeAccess`'s return value is the
  function's actual observable contract, used directly by its one caller
  and now importable by name.
- **No test asserts implementation detail or private structure.** Every
  assertion is on `Response.status`, response body fields, or the recorded
  `.eq()` call arguments — the last of these is the one place worth a
  second look, and it holds up: the fake's `.eq()` recording is the
  *mechanism* for asserting an external, observable fact (which columns a
  real Supabase client would filter on), not an internal call-count check
  on this codebase's own logic.
- **Naming matches this repo's convention** (`loyalty-config.test.ts`,
  `influencers.test.ts`): domain-language test names, one behavior per
  `Deno.test` block.
