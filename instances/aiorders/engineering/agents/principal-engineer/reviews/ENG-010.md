# Code review — ENG-010 (round 3)

diff against the branch point (the build hop plus both fix hops), not just

## Rounds 1 and 2 recap

- **Round 1 — fail.** Stale-response race: `fetchNotes`/`handleAddNote`
  applied an async response without checking it was still for the
  influencer currently open. Fixed with a `useRef` set synchronously at
  click time (not the finding's own suggested closure comparison, which
  would have broken every normal open — see the ticket log for why).
- **Round 2 — fail.** `influencer_notes` shipped with no row-level
  security, leaving the one risk this ticket's PRD names as the thing it
  cannot get wrong (an influencer reading staff commentary about
  themselves) reachable via direct PostgREST with the influencer's own
  session, a path the edge-function check never touches. Fixed by adding
  `ENABLE ROW LEVEL SECURITY` plus an admin/sub-admin policy, matching the
  existing `proxy_sessions_audit_logs` precedent.

Full detail on both: `agents/principal-engineer/notebook/2026-09-02-review-log.md`.

  out of this hop's scope"); this is the equivalent for the error path,
  not a new category.
- **RLS policy's `role`-only scope** — see above; carried here as a named,
  non-blocking, pre-existing pattern rather than omitted.

none reach the bar of a fourth review round: each is either a codebase-wide

## Test quality (shape, not coverage)

  real, not vacuous** — checked by tracing what would happen if
  `hasInfluencerAdminAccess` wrongly allowed `role: 'influencer'`: the flow
  would reach `listInfluencerNotes`, which calls `auth.adminSupabase.from(...)`
  on `uncalledAuth`'s throwing Proxy, caught by that function's own

  (`captured.author_id`), not the response echo — a regression that read
  `author_id` from the request body would be caught here specifically,
  not just incidentally by some other assertion.
- No test asserts on private/internal structure; every assertion is on
  `Response.status`, response body fields, or the captured `.insert()`
  argument.
- Naming and fake-client shape match this file's own house style
  (`influencers.test.ts`'s chainable-fake convention, confirmed by reading
  both files side by side).
