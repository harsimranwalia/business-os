  same optionality annotations (`"item_id": "cQ1IIsOGt4" | null`, `"note":
  "medium spice" | null`). This comment is the table's *only* schema
  documentation (no tracked `CREATE TABLE`), so a mismatch here would be a
  real defect per `engineering-standards.md`'s "a comment that asserts a
  property the code does not have" rule — it does not mismatch.

  correctly adds nothing pricing-related.

  `20260807000001_add_heard_about_us_to_catering.sql` (the design's own named

- **Shape-in-comment for the jsonb column** — matches
