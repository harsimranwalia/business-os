  `try/catch` (confirmed by reading both files in full), converting the throw

  `requireRestaurantAccess` throw path (`utils.ts:126`) and, one line beyond

  only named `requireRestaurantAccess` for this control; the ticket's own log
  flags the `offers.ts` addition explicitly as "design silent, standards
  apply" rather than silent scope creep — agreed. `security-baseline.md`'s
  A09 control has no carve-out for which response convention denies the
  request, so extending it was the correct call, not an unrequested addition.
- **One-way doors** — none, matches `adrs: []` / `one_way_doors: []` in the
  design's own frontmatter. Rename of a zero-external-caller function
